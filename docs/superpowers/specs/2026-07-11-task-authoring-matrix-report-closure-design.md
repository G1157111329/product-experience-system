# 任务录入、数据矩阵与报告闭环增量设计

日期：2026-07-11  
状态：已确认，进入实现  
基线：`2026-07-10-task-detail-unified-layout-design.md`

## 1. 目标与不变边界

本增量沿用已经确认的任务详情统一布局，不再逐页重新定稿。目标是减少重复导航、减少显式“进入编辑/确认问题/点击保存”，并保证任务录入的数据在报告详情、公开分享和打印/PDF中一致呈现。

冻结报告的整体视觉版式、Tab 视觉结构和 PDF 模板不重排；本轮只修正 Tab 是否出现、问题内容、附录素材和公开访问契约。

## 2. 任务详情统一布局

- 顶部任务状态卡承担任务内模块切换，桌面端和移动端不再显示第二套“录入目录”。
- 顶部状态卡保留五感体验、单一食谱功能、数据矩阵、对比矩阵、报告信息；移除“问题管理”。任务问题数量仍可在任务标题上下文中轻量展示。
- 功能/食谱使用“紧凑食谱列表 + 当前食谱工作区”。食材参数以食谱名称下方的小标签摘要呈现；步骤、效果评价和问题点在同一工作区直接编辑。
- 食谱/步骤问题点保存后直接同步问题管理，不再增加独立“问题输出—确认进入问题管理”步骤。
- 删除入口统一为低强调图标或更多菜单；只有最终确认弹窗使用破坏性强调。

## 3. 素材证据与图片编辑

- 任务底部保留唯一的全宽“素材证据”区；数据矩阵内部不再显示“素材池”。
- 四个大按钮收敛为一个主要“添加素材”入口及紧凑来源菜单（拍照、录像、图片、视频），缩略图网格直接呈现已上传素材。
- 上传区在可见、可交互时支持 Ctrl/Cmd+V 粘贴剪贴板图片；粘贴不抢占文本输入框事件。
- 图片原图预览提供“编辑”入口，复用共享编辑器，至少覆盖裁剪、旋转、水平/垂直翻转、画笔、撤销和保存。保存后刷新当前素材，不改变素材与记录、步骤、问题的关联关系。

## 4. 数据矩阵编辑规则

- 文本、数值和问题点均使用本地草稿；仅在失焦或按 Enter 后提交。提交期间不重建整张表，不抢焦点，不覆盖仍在编辑的草稿。
- 列按固定区域排序：层级类目 → 主素材 → 对比/输入指标 → 计算列 → 效果素材 → 效果评价 → 问题点。新增列插入所属区域末尾，并为后续区域整体让位。
- 新增三级细项后，原三级细项继续保留可见、可编辑输入；层级合并只影响视觉合并，不得吞掉输入控件。
- 清空/停用采用低强调操作，但保持明确确认和原子清理契约。

## 5. 报告数据闭环

- 报告生成在任务的非归档矩阵中按更新时间倒序查找，选择第一份“有实质内容”的矩阵；最新空矩阵不得遮蔽更早的有效矩阵。
- 数据矩阵问题点必须进入报告“问题”Tab，并复用报告专用问题聚合链路。展开结构固定为：问题点；可选的问题详情；附录素材；整改。空的问题详情不渲染。
- 报告详情、公开分享、打印/PDF读取同一冻结数据和问题素材聚合结果。矩阵单元格、食谱步骤、效果评价、复评估素材均纳入兜底关联。
- 分享令牌页面保持无需登录、只读；通过自动化测试锁定，避免认证中间件回归。
- 打印预处理不对 `data:` 占位图发起网络请求，避免 CSP 报错；问题附录素材加入预签名和 base64 转换队列。

## 6. 验收门槛

- 真实任务页无“录入目录”和顶部“问题管理”卡；功能/食谱不再出现独立问题确认面板。
- 数据矩阵连续输入不丢焦、不漏字；失焦后刷新仍保留值；列顺序符合固定区域。
- 粘贴图片上传、图片编辑保存可在真实浏览器完成。
- 指定报告 `837beb71-dcbe-48e7-ab24-905710ad45fc` 在重新生成或兼容读取后可显示有内容的数据矩阵；空矩阵不出现 Tab。
- 问题详情、公开分享和打印页的问题数、问题文本、附录素材一致。
- `pnpm ts-check`、`pnpm lint`、相关契约测试、生产构建和 Docker 真实页面回放全部通过。
