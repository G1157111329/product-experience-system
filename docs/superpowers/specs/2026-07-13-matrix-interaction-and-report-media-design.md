# 对比矩阵、数据矩阵与冻结报告素材增量设计

日期：2026-07-13
状态：已确认
基线：`2026-07-11-platform-interaction-convergence-design.md`

## 1. 目标

在不改变矩阵事实数据、不重建冻结报告合同的前提下，分别优化两类矩阵的核心任务：

- 对比矩阵帮助用户围绕同一细项即时比较 A/B/C 对象。
- 数据矩阵保留 Excel 型全局扫描和连续录入效率。
- 冻结报告中的图片和视频按证据语义分级呈现，避免所有素材统一压缩为难以辨认的 48×48px。

本设计采用混合交互，不强行让对比矩阵和数据矩阵使用同一种版式。

## 2. 对比矩阵

### 2.1 桌面端：紧凑矩阵与细项聚焦编辑

桌面端保留“左侧对比项目、右侧 A/B/C 对象”的横向比较关系，但常态单元格不再完整展开素材、效果结论、过程记录和问题点四组表单。

常态单元格只显示：

- 首张素材或素材数量。
- 一行效果结论摘要。
- 问题数量和状态。
- 当前单元格保存状态。

点击细项名称或任一对象单元格后，在该细项行下方展开完整的“对比编辑区”：

- A/B/C 对象继续并排，保持即时比较。
- 每个对象列按“素材、效果结论、过程记录、问题点”排列。
- 当前对象有明确焦点边界，但其他对象内容仍可见。
- 切换细项时先提交当前未保存草稿；提交失败则保留当前聚焦区并显示错误。
- 再次点击当前细项或使用收起按钮关闭聚焦区。

大类和细项树保持在矩阵左侧。大类小结在对应大类末尾显示，不占用每个对象单元格。

### 2.2 移动端：细项固定，对象纵向比较

移动端不渲染桌面宽表，也不要求用户在对象列之间横向拖动。

- 顶部显示当前大类、细项和完成进度。
- 当前细项下按 A、B、C 顺序纵向显示对象卡片。
- 每张对象卡常态显示素材缩略图、效果摘要和问题数量；点击后原位展开完整编辑字段。
- 页面底部提供“上一细项”“下一细项”，并显示当前位置，例如 `3 / 12`。
- 切换细项时保持同一对象排序，帮助用户建立稳定比较心智。
- 对象、大类、细项管理收敛到顶部更多菜单，不在每张卡片重复大面积删除按钮。

移动端优先完成当前细项的多对象比较，不追求在一屏同时展示全部矩阵。

### 2.3 对象与结构管理

- 对象新增、重命名和排序集中在紧凑对象管理区。
- 删除对象、大类或细项使用低强调入口，确认弹窗显示受影响单元格和素材数量。
- 清空并停用矩阵保持独立高风险操作，不与普通删除混在一起。
- 结构为空不代表矩阵已使用，继续复用 canonical meaningful-content 判定。

## 3. 数据矩阵

### 3.1 默认直达当前实例

任务级数据矩阵入口默认打开当前有效实例，不先展示多张大尺寸矩阵卡。

当前实例选择规则：

1. 优先当前非归档、最近编辑且有实质内容的矩阵。
2. 没有实质内容时，选择最近编辑的非归档草稿。
3. 没有实例时，沿用现有自动创建空矩阵行为。

多个历史、重复或测试实例通过标题旁的紧凑选择器访问。选择器显示名称、状态、更新时间和是否有内容；删除或停用不放在列表主视觉中。

### 3.2 桌面端：保留表格，增强定位

现有 V3 桌面表格继续作为主录入界面：

- 冻结一级、二级、三级层级列，使横向查看指标时不丢失行上下文。
- 表格上方增加分区跳转：层级、主素材、输入指标、计算结果、效果素材、效果评价、问题点。
- 分区跳转滚动到对应列区域，不改变列顺序。
- 数值、短文本和公式结果继续直接在单元格中录入或查看。
- 素材、长文本、效果评价和问题点可在选中行的聚焦编辑区中放大处理，但原单元格仍显示摘要。
- 聚焦编辑区不能遮挡表头和当前行层级路径。
- 批量粘贴、公式点选和列配置继续在表格模式完成，不迁移到卡片模式。

### 3.3 移动端：逐行分区卡片

沿用现有逐行卡片，不重新实现第二套矩阵数据：

- 顶部显示当前行层级路径和 `当前行 / 总行数`。
- 提供上一行、下一行快速切换。
- 字段按输入、计算、素材、评价、问题分组。
- 没有内容且不是必填的分组默认折叠；存在错误或问题的分组保持展开。
- 数值、文本和问题点统一通过失焦或 Enter 提交。
- 切换行前提交当前草稿；失败时不离开当前行。

### 3.4 不改变的能力

- 列分区顺序仍为：层级 → 主素材 → 对比/输入 → 计算 → 效果素材 → 效果评价 → 问题点。
- meaningful-content、清空停用、公式 DSL、冻结报告投影和素材关联合同不改变。
- 桌面表格仍允许必要的内部横向滚动；冻结报告阅读态不允许横向拖动条。

## 4. 冻结报告素材

### 4.1 语义化尺寸

`ReportMediaPreview` 从通用 `xs/sm/md/lg` 尺寸升级为报告语义：

| 语义 | 使用位置 | 桌面端 | 移动端 |
|---|---|---|---|
| `primary` | 功能效果主素材、关键结论素材 | 160–220px，自适应网格；单张最大约 320px | 两列；极窄屏单列 |
| `evidence` | 步骤、过程和一般证据 | 112–144px | 两列 |
| `appendix` | 问题附录、整改和复评素材 | 96–128px | 两列或三列，按可用宽度 |
| `compact` | 矩阵单元格摘要 | 72–80px | 64–72px |

图片默认使用 4:3 裁切预览，点击后查看完整原图。视频默认使用 16:9 poster，显示播放标识；可用时显示时长。

### 4.2 数量控制

- 功能效果主素材默认显示最多 6 张。
- 步骤和问题附录默认显示最多 4 张。
- 矩阵紧凑摘要默认显示前 2 张，其余显示 `+N`。
- “查看全部”在当前内容块原位展开，不跳到独立素材池。
- 收起后保持用户当前滚动位置。

### 4.3 内容层级

- 主效果素材紧随效果评价文字，承担第一视觉证据。
- 问题附录素材位于对应问题点和可选问题详情之后、整改之前。
- 整改和复评素材与原问题证据分组，不混成一排。
- 矩阵素材依附对应记录或对象，不在 Tab 底部再次汇总为无上下文图库。

### 4.4 详情、分享与打印

- 报告详情与匿名分享复用同一媒体组件、语义尺寸和展开规则。
- 打印/PDF只复用素材语义，不复用网页像素尺寸。
- 打印主素材按纸张栏宽排版；问题附录和整改素材使用固定网格并避免跨页裁断。
- 视频在打印中呈现 poster、视频标识和文件名，不尝试嵌入可播放控件。

### 4.5 媒体技术边界

- 保留现有缩略图、视频 poster、懒加载、预签名 URL和全屏预览链路。
- 不用原始大图直接填充列表。
- 预览图加载失败显示稳定占位，不导致卡片高度跳变。
- `data:` 占位图不进入网络预取或打印转换请求。

## 5. 组件边界

建议形成以下独立组件：

- `ComparisonMatrixOverview`：紧凑单元格和细项选择。
- `ComparisonItemEditor`：一个细项下的多对象完整编辑。
- `ComparisonMobileItem`：移动端当前细项与对象卡片。
- `MatrixZoneNavigator`：数据矩阵分区定位。
- `MatrixRowFocusEditor`：长内容和媒体的行级聚焦编辑。
- `ReportMediaGrid`：按 `primary/evidence/appendix/compact` 呈现冻结素材。
- `ReportMediaPreview`：只负责单个素材预览，不自行决定业务尺寸。

这些组件只消费现有矩阵、素材和冻结报告数据，不建立第二套持久化状态。

## 6. 验收标准

- 桌面对比矩阵常态一行不再被四组完整表单撑到接近一屏高度。
- 用户打开一个细项后可同时查看和编辑 A/B/C 对象，不需要逐对象切换页面。
- 移动端对比矩阵无桌面宽表和横向拖动条，可通过上一项/下一项完成全部细项。
- 数据矩阵入口默认直达当前实例；历史实例可访问但不占据首屏。
- 数据矩阵桌面端保留全局表格、批量粘贴和公式能力；移动端保持逐行卡片。
- 数据矩阵横向滚动后仍能看到当前层级路径，并可从分区导航跳转到目标列。
- 报告主效果素材无需打开原图即可辨认主体；问题附录仍保持合理信息密度。
- 视频预览不再被强制裁成与图片相同的正方形。
- 详情与匿名分享的素材数量、顺序、语义尺寸和展开规则一致。
- 打印/PDF包含相同素材，但按纸张规则排版，不复制网页尺寸。
- 390、768、1024、1440宽度下无非必要页面级横向滚动、文字重叠或底部导航遮挡编辑控件。
- 所有矩阵草稿切换前可靠提交；提交失败保留原输入和当前上下文。
- 浏览器控制台无新增错误，图片缩略图、S3预签名、视频 poster和全屏预览链路正常。

## 7. 非目标

- 不把数据矩阵改成纯卡片系统。
- 不把对比矩阵改成一次只看一个对象。
- 不更改矩阵数据库模型、公式语义或 meaningful-content 定义。
- 不将冻结报告素材抽离成脱离问题、步骤或矩阵上下文的独立图库。
- 不用统一放大所有缩略图代替信息层级设计。
