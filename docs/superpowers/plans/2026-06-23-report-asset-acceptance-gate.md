# 报告资产验收闭环计划

## 目标

本阶段目标不是继续扩展新功能，而是证明四类报告资产能够从同一套数据/快照模型出发，完成体验计划内录入/编辑、报告生成或快照发布、报告中心阅读、报告详情连续阅读、就地证据、只读分享、PDF/打印交付和 Golden 数据重复验收。

验收结论必须由脚本、浏览器路径、PDF 输出或明确的缺口清单支撑，不能只依赖代码存在或接口烟测。

## 当前判断

已进入收口范围：

- 对比矩阵采用单元格内联录入：图片/视频、效果结论、过程记录、问题点、评分和标签在单元格内直接编辑。
- 报告详情模型、比较报告、报告快照、分享页和 PDF 路由已具备基础代码路径。
- Golden 数据、报告详情契约检查和 V2.6 成功指标脚本已存在。
- 基础质量门禁最近已跑过 `lint`、`ts-check`、`build`，并做过局部浏览器验证。

未完成收口：

- PRD V2.5/V2.6/V2.7、执行计划和 contract 脚本仍有历史漂移，旧脚本不能继续要求弹窗式矩阵编辑或过期变量名。
- Golden 验收尚未完整覆盖四类报告、分享页、PDF、移动端、失败态和权限负测。
- PDF Job、完整 Excel 迁移、Row AI / Report AI 高级闭环仍应作为后续阶段，除非阻塞当前验收。
- 历史 Excel 大文件只作为本地/外部验收素材，不进入仓库。

## 范围

纳入本阶段：

- PRD 与实现对表：每个核心验收项映射到文件、脚本、页面路径或浏览器步骤。
- 修正 contract/metrics 脚本，确保它们验证当前内联矩阵和同源快照模型。
- Golden 数据覆盖普通报告、图片矩阵对比、指标对比、型号阶段合并、自定义合并。
- 真实路径验收：登录、建计划、录素材、填矩阵、生成报告、报告中心定位、详情阅读、分享、PDF。
- PDF 预检验收：AI 未确认、证据缺失、视频缺封面、超宽矩阵、A3/A4 profile。
- 权限验收：匿名、普通用户、负责人、管理员、分享访问。

排除本阶段：

- 不新增一级对比中心。
- 不做完整 Excel 自动迁移工程。
- 不扩展 Row AI / Report AI 高级生成闭环。
- 不把历史 Excel 大文件提交到 git。
- 不把 PDF 当作主阅读模式；PDF 只做交付输出。

## 验收闸门

### Gate A：PRD 与契约对齐

- [ ] V2.5/V2.6/V2.7 的已实现、待验证、延期项在计划文档中有清晰状态。
- [ ] contract 脚本不再检查旧版弹窗式矩阵编辑、过期变量名或乱码文案。
- [ ] contract 脚本显式检查单元格内联媒体、文本区、评分、标签、保存和拖拽/选择素材。
- [ ] 每条核心验收项都有命令、页面路径或浏览器操作作为证据来源。

验证：

- `pnpm.cmd exec tsx scripts\check-v2.3-contract.ts`
- `pnpm.cmd check:golden`
- `pnpm.cmd check:v2.6-success`

### Gate B：Golden 数据可复跑

- [ ] Golden 数据包含至少五类资产：普通报告、图片矩阵对比、指标对比、型号阶段合并、自定义合并。
- [ ] Golden 数据包含发布/未确认 AI/PDF 失败/高风险未关闭问题等状态。
- [ ] Golden 数据不依赖开发机隐式本地文件。

验证：

- `pnpm.cmd check:golden`
- `pnpm.cmd check:v2.6-success`

### Gate C：用户路径闭环

- [ ] 体验计划内可创建普通任务并生成报告。
- [ ] 体验计划内可创建对比任务，单元格直接录入图片/视频、效果结论、过程记录和问题点。
- [ ] 报告中心能定位普通、对比、型号合并、自定义合并报告。
- [ ] 报告详情能按模块连续阅读，不依赖附录理解关键证据。
- [ ] 分享页只读可访问，隐藏编辑/审核操作。

验证：

- `pnpm.cmd smoke:e2e`
- 浏览器验收记录：桌面 1440px、移动宽度、分享页、报告详情页。

### Gate D：证据与阅读体验

- [ ] 报告首屏 5 秒内能看清目的、结论、风险和下一步动作。
- [ ] 证据素材贴在问题、步骤、效果、矩阵单元格等业务对象旁边。
- [ ] 对比矩阵桌面端横向阅读正常，移动端不出现文本竖排、遮挡或主路径被阻断。
- [ ] 视频以可识别预览或播放入口呈现，图片可放大查看。

验证：

- 浏览器截图与 DOM 断言。
- `pnpm.cmd check:golden`

### Gate E：PDF、分享与权限

- [ ] PDF 基于快照生成，不使用可变草稿数据。
- [ ] 对比矩阵 PDF 使用 A3 横向 profile，普通/型号/自定义报告使用对应 A4 profile。
- [ ] PDF 预检能暴露 AI 未确认、缺证据、视频缺封面、超宽矩阵等问题。
- [ ] 分享页只读，未授权用户不能访问内部报告详情 API。
- [ ] 普通用户不能创建越权分享或管理他人报告。

验证：

- `pnpm.cmd smoke:e2e`
- 浏览器访问 `/api/reports/[id]/pdf` 与 `/reports/share/[token]`。

### Gate F：基础质量门禁

- [ ] `pnpm.cmd lint`
- [ ] `pnpm.cmd ts-check`
- [ ] `pnpm.cmd build`
- [ ] `pnpm.cmd check:golden`
- [ ] `pnpm.cmd check:v2.6-success`
- [ ] `pnpm.cmd smoke:e2e`
